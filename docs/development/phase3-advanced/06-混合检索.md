## 1. 目标与范围

向量检索（语义）+ 关键词检索（BM25 精确匹配）**并行执行**，RRF 融合去重，提升召回率。术语 / 型号 / 代码 / 编号这类精确词，向量检索经常召不回，关键词检索正好接住。本环节负责"**召回广**"；"精度准"由 Phase 3-02 重排负责。

## 2. 任务拆解

- [ ] 安装依赖：`rank_bm25`（BM25 实现）、`jieba`（中文分词）
- [ ] `app/core/keyword_index.py`：
  - 构建：chunk 文本 → jieba 分词 → BM25 内存索引；启动时全量重建（秒级）
  - 查询：`search(query_text, top_k) -> list[(chunk_id, score)]`
  - 同步：文档增删改（Phase 2-02 / 3-05）时同步更新索引（MVP 可先重启全量重建兜底）
- [ ] `app/core/hybrid_retriever.py`：
  - `retrieve(query, kb_id)`：向量检索（top-k=10）∥ 关键词检索（top-k=10，jieba 分词）
  - RRF 融合：`score = Σ 1 / (60 + rank)`，按 `(doc_id, chunk_index)` 去重，融合后候选集**放宽到 top-20**（供重排）
  - 混合模式下**移除 similarity_threshold 硬门槛**（0.3 保留为观测指标），质量交给 RRF 排序 + 重排
- [ ] `rag_pipeline` 接入：`retriever.retrieve` 替换为 `hybrid_retriever.retrieve`；配置开关 `HYBRID_RETRIEVAL_ENABLED`（默认开，关闭时行为与 Phase 2 一致）
- [ ] 与 Query Rewrite 接线（Phase 3-01）：改写查询喂**向量侧**；关键词侧默认只用**原始问题词**（同义词扩展可配 `KEYWORD_USE_REWRITTEN=false`，默认关 —— 词面精确优先）
- [ ] 测试：术语查询召回验证（`qwen-plus`、`SSE`、错误码等精确词必须命中）

## 3. 设计要点

- **互补性**：向量检索擅长语义改写（"定价多少" ↔ "收费标准"），关键词检索擅长精确词（型号 / 代码 / 编号）—— 两者取并集
- **中文分词是前提**：jieba 分词后建 BM25；不分词的话整句一个 token，检索等于失效
- **RRF 不需要分数可比性**：余弦相似度与 BM25 分数量纲不同，加权需归一化标定；RRF 只看排名（k=60），零参数
- **候选集先放宽、再收窄**：各取 top-10 → 融合留 top-20 → Phase 3-02 重排砍到 top-5。召回不宽，重排无米下锅
- **阈值语义变更**：0.3 相似度阈值在混合模式下会误杀"关键词独有命中"（向量分低但关键词强相关），故移除硬门槛
- **索引同步与一致性**：关键词索引与 ChromaDB 必须同源同更新 —— 文档入库 / 删除（Phase 2-02 / 3-05）都要同步，否则检索结果与知识库内容不一致
- 专有名词进 jieba 自定义词典（`jieba.add_word`，词典文件可配）：型号、产品名分词不准会直接漏召回

## 5. 验收标准

- [ ] 含精确术语的问题（如"qwen-plus 的上下文窗口"）→ 关键词侧命中包含该术语的 chunk（纯向量模式可能漏）
- [ ] 语义改写问题（如"怎么计费"）→ 向量侧命中 —— 混合后两种提问方式都能召回
- [ ] RRF 融合去重正确：同一 chunk 在两个结果中都出现时只保留一次，分数正确
- [ ] `HYBRID_RETRIEVAL_ENABLED=false` 时行为与 Phase 2 一致（回归）
- [ ] 样例集（Phase 2-04）对比：混合模式召回 ≥ 纯向量模式（重点看术语类题目）
- [ ] 文档删除后关键词索引同步（检索不到已删内容）

## 6. 风险与注意事项

- **内存驻留**：BM25 索引在内存，几十万 chunk 内可接受；超出考虑 SQLite 持久化，或迁移 Milvus 用其原生稀疏向量（附录 B 路径）
- **噪声预期内**：关键词命中会有词面匹配但语义无关的项 —— 由 Phase 3-02 重排负责踢出，**不要用阈值硬砍**（会连独有命中一起砍掉）
- **重建成本**：启动全量重建在秒级；文档操作频繁时可改为增量更新（后置优化）
- **与重排的分工边界**：本环节只管"召回 + 合并"，别在融合里做质量过滤 —— 职责重叠会造成参数互相打架
