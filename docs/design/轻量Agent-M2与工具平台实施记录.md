# 轻量 Agent M2 与工具平台实施记录

日期：2026-09-18。用户确认按当前方案继续实施。本次完成通用工具平台骨架和 M2 的文档相邻阅读、数值与日期计算；没有启用 Agent、没有接入 MCP、天气或网页服务，没有修改本地 `.env`，没有执行 Git push。

## 工具平台

- 新增 `ToolPlatform`、`ToolDefinition` 与 `ToolPolicy`。每个工具声明名称、版本、输入 Schema、处理器、数据分类、适配器类型、开关与缓存策略。
- 模型只能获得当前开关允许的工具 Schema；服务端预注册工具，不能由模型加载任意 Python、MCP Server、URL 或代码。
- 平台统一处理调用预算、参数大小/Schema 校验、请求内缓存、证据登记、统一状态、耗时日志和异常脱敏。缓存命中复用同一证据引用。
- 当前适配器均为 `local`；`mcp` 和 `http` 是预留的声明类型，不代表已经可连接外部服务。未来新内部工具只需新增工具声明和处理器，不修改 Agent 编排循环。

## M2 工具

- `search_knowledge` 对已支持的分块签发仅限本次会话的随机文档句柄；弱候选只提供定位句柄而不提供正文，使例外条款可在展开后重新核验；不会暴露可被模型伪造的文件路径。
- `read_document_section` 只能读取句柄中心分块前后各最多 2 块，且重新检查可读知识库、文档已发布、有效期、发布版本和中心分块存在性。撤销发布、过期、版本变化或跨会话使用都会被拒绝。
- 展开后的片段重新经过证据门槛；未通过时不当作可回答资料。首期仅支持相邻分块，不宣称已经阅读完整章节或整篇文档。
- `calculate` 使用 `Decimal`，支持加减乘除、求和、均值、百分比变化；拒绝 NaN、Infinity、除零、超长数字与通用表达式。
- `date_calculate` 支持自然日差、按日/周偏移、日期级截止状态和精确时长；日期级截止不虚构具体时刻，夏令时歧义的本地时间要求显式偏移。
- 计算可携带 `input_refs`，仅允许引用本次请求的证据登记表；计算结果证明运算，不证明输入材料的事实本身。

## 配置与回退

- 新增 `DOCUMENT_READ_ENABLED=false`、`CALCULATOR_ENABLED=false`。即便将来开启 `AGENT_ENABLED`，M2 工具也仍默认不出现在模型目录。
- 本阶段未新增数据库字段或迁移。关闭上述开关即可从 Agent 目录移除对应能力；`AGENT_ENABLED=false` 仍回退到原 RAG 路径。
