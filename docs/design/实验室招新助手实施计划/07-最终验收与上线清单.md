# 07：最终验收与上线清单

> 状态：待执行
>
> 前置依赖：01～06 已分别验收
>
> 目标：确认整套系统可以演示、可以恢复、可以量化、没有明显越权和内容泄漏

## 1. 验收原则

1. 不只验证页面按钮，要直接调用 API 验证后端边界；
2. 不只验证成功路径，要注入网络、任务、索引和权限失败；
3. 不使用真实密钥、密码和个人资料作为测试输出；
4. 不新增测试用例，使用现有测试、构建检查、脚本和人工验收；
5. 所有量化数据记录运行环境、版本和配置；
6. 任一权限泄漏、未审核资料泄漏或旧索引损坏都属于阻断问题。

## 3. 数据库与迁移验收

- [ ] MySQL 已备份；
- [ ] ChromaDB 已备份；
- [ ] `alembic current` 指向 head；
- [ ] 从当前正式版本 upgrade 成功；
- [ ] 在测试副本 downgrade 成功；
- [ ] 再次 upgrade 后数据量一致；
- [ ] 旧 documents、chunks、sessions、users 数据没有丢失；
- [ ] 旧 ACL 已按 M0 决策退役或迁移；
- [ ] 所有新增索引和唯一约束生效。

## 4. 角色与权限验收

### 4.1 guest

- [ ] 只能进入问答区；
- [ ] 只能读取 guest 级已发布资料；
- [ ] 不能进入知识库和系统管理页面；
- [ ] 直接调用管理 API 返回 401/403；
- [ ] 访客之间不共享可识别会话和长期记忆。

### 4.2 student

- [ ] 可管理自己的会话和长期记忆；
- [ ] 可读取 guest/student 级已发布资料；
- [ ] 不能读取其他用户会话和记忆；
- [ ] 不能进入两个管理区；
- [ ] 可以申请成为 editor，不能申请 admin。

### 4.3 editor

- [ ] 可进入知识库工作台；
- [ ] 可管理授权等级范围内的资料；
- [ ] 可修正 AI 标签和提交预审；
- [ ] 不可最终发布、归档和回滚；
- [ ] 不可管理用户角色、成员申请和完整审计；
- [ ] 不能操作 admin 级知识库。

### 4.4 admin

- [ ] 可管理全部知识库；
- [ ] 可发布、驳回、归档和回滚；
- [ ] 可批准成员申请；
- [ ] 可管理用户和角色；
- [ ] 可查看审计和全部后台任务；
- [ ] 总管理员密码不是硬编码默认值。

## 5. 文档生命周期验收

- [ ] 上传后只进入隔离区；
- [ ] 技术状态和治理状态分别显示；
- [ ] 解析失败不会产生正式向量；
- [ ] AI 初标失败仍可人工审核；
- [ ] 敏感 blocking 文档不能提交发布；
- [ ] editor 预审后仍不可被用户检索；
- [ ] admin 批准且发布成功后才进入回答；
- [ ] 版本历史、审核人、发布人和意见可追溯；
- [ ] 归档和过期资料立即被 Prompt 终检排除；
- [ ] 回滚后回答使用目标历史版本。

## 6. 索引一致性验收

- [ ] MySQL published doc_id 集合与正式 Chroma doc_id 集合一致；
- [ ] 正式 Chroma Chunk 数与 MySQL 已发布 Chunk 数一致；
- [ ] BM25 只包含有效已发布 Chunk；
- [ ] 向量维度全部符合配置；
- [ ] 发布期间旧索引仍可回答；
- [ ] docs_new 校验失败不切换；
- [ ] swap 失败后旧索引可恢复；
- [ ] 过期向量即使残留也无法进入 Prompt；
- [ ] 删除知识库后相关正式、临时和旧 collection 均可清理。

## 7. 问答质量验收

- [ ] 使用冻结 holdout 运行完整评测；
- [ ] Recall@5 达到最终门禁；
- [ ] MRR@5 达到最终门禁；
- [ ] Citation Precision 达到最终门禁；
- [ ] Groundedness 达到最终门禁；
- [ ] No-answer Accuracy 达到最终门禁；
- [ ] 权限泄漏测试为 0；
- [ ] 关键招新问题错误为 0；
- [ ] 多子问题覆盖率有记录；
- [ ] P50/P95、Token 和成本有记录；
- [ ] 每个失败题能看到检索各阶段候选。

## 8. 会话与记忆验收

- [ ] 短期窗口超过阈值后摘要压缩；
- [ ] 摘要持久化并在重启后恢复；
- [ ] 历史上下文不超过 4,000 Token 配置预算；
- [ ] 长期记忆按 user_id 隔离；
- [ ] 访客不获得跨身份长期记忆；
- [ ] 用户可查看、编辑和删除自己的长期记忆；
- [ ] 管理员不能通过普通管理接口查看私人记忆正文；
- [ ] 逻辑删除会话不出现在活跃列表；
- [ ] 恢复会话后所有者校验仍生效。

## 9. 后台任务验收

- [ ] inline 模式可完成文档处理和发布；
- [ ] rq 模式产出一致；
- [ ] API 重启不丢任务；
- [ ] Worker 重启后任务恢复或明确失败；
- [ ] 重复投递不产生重复数据；
- [ ] 同一知识库 publish/reindex 互斥；
- [ ] Redis 故障时问答仍正常；
- [ ] 管理写操作收到可重试的 503；
- [ ] editor 只能看到授权范围内任务；
- [ ] admin 可以重试最终失败任务。

## 10. 审计与安全验收

- [ ] 登录成功、失败和权限拒绝有审计；
- [ ] 角色变更、发布、归档、回滚和删除有审计；
- [ ] request_id 可关联 HTTP、应用日志和审计；
- [ ] 审计不含密码、JWT、API Key 和数据库 URL；
- [ ] 上传文件名不会直接拼接为不安全服务器路径；
- [ ] 登录、注册、问答和上传分别限流；
- [ ] Refresh Cookie 的 HttpOnly/SameSite/Secure 符合部署环境；
- [ ] CORS 只允许配置的前端源；
- [ ] `.env`、data 和内部资料未被 Git 跟踪；
- [ ] 总管理员首次使用后已更换密码。

## 11. 招新体验与反馈验收

- [ ] 首屏有实验室介绍和推荐问题；
- [ ] 推荐接口失败不影响自由提问；
- [ ] 无答案时不编造联系方式和结论；
- [ ] 部分子问题无证据时明确指出；
- [ ] 用户可以反馈错误、过期、引用和不完整；
- [ ] 用户不能查看他人反馈；
- [ ] 反馈不能直接修改知识库；
- [ ] 管理员可把脱敏反馈加入评测候选；
- [ ] 修订、发布、评测和反馈关闭形成完整记录。

## 12. 故障注入场景

必须人工验证：

1. DashScope 返回 429；
2. Embedding 中途失败；
3. 重排接口不可用；
4. MySQL 短暂不可用；
5. Redis 不可用；
6. Worker 在任务中途退出；
7. docs_new 数量校验失败；
8. 同一知识库重复触发发布；
9. 两个管理员同时审批同一版本；
10. 学生伪造 admin 接口请求；
11. Chroma 中残留已过期 doc_id；
12. 上传包含测试密钥格式的文档。

每个场景记录：预期、实际结果、request_id、是否触发兜底、是否产生脏数据。

## 15. 最终放行条件

以下任一问题存在，不允许标记整体完成：

- 未审核资料可被检索；
- 用户可越权访问知识库、会话或记忆；
- 发布失败破坏旧正式索引；
- 任务重试产生重复数据；
- 审计或日志泄漏密码、密钥或私人记忆；
- 简历指标无法从评测结果复现。
